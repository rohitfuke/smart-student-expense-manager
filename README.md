# SmartSpend – Smart Student Expense & Budget Manager

SmartSpend is a full-stack student expense management and spending analytics application designed to help students track expenses, manage budgets, and understand their spending patterns through data-driven insights.

The project combines a React frontend, FastAPI backend, SQL database, Python-based analytics, and Power BI visualization into one integrated expense intelligence system.

---

## 🚀 Key Features

- Add and manage daily expenses
- Categorize expenses
- Set and track a monthly budget
- View total and average spending
- Analyze spending by category
- Analyze daily, weekly, and monthly spending trends
- Detect unusual spending patterns
- Generate smart spending insights
- Interactive charts and analytics dashboard
- SQL-based analytical queries
- Python-based exploratory data analysis
- Power BI dashboard for business-style reporting
- Persistent expense storage using SQL database
- REST API integration between frontend and backend
